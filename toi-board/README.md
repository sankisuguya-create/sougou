# といボード（見本）

3年総合「西宮博」で、児童が問いを **出す→直す→えらぶ→見合う（予想→しりたい！シール）→けっか** と進めるためのボード。QFT（Right Question Institute）準拠。

## 見本の動かし方
`index.html` をブラウザで開く。上の「見本の切り替え」で先生／児童を切り替える（本番は Google アカウントで自動判定）。
1. 先生 →「見本のデータ」で7班分を入れる
2. 先生 → 段階を「4 見合い会」に
3. 児童 → 予想を書く（または「よそうできない！」）→ シールを貼る（1人3枚まで）

保存は localStorage（同じブラウザの別タブに即時反映）。本番は GAS ＋スプレッドシートに差し替える（`Platform` 層のみ交換）。

## 検査
`NODE_PATH=$(npm root -g) node tests/check.cjs`

設計の理由は [docs/design.md](docs/design.md)。児童の実名・学級情報はこのリポジトリに置かない。
