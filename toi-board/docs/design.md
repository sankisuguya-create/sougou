# 設計の理由

- **予想 → シールの順**：予想（または「よそうできない！」）を書くまでシールは押せない。予想を消すとシールも外れる。「面白そう」を感覚でなく、自分の予想との距離で判断させるため。
- **面白さ＝しりたい！の数**：予想が割れる問いだけでなく、予想すら難しい問いも包摂する。
- **種類（⇆わかれる／？なぞ／✓たしかめ）は班が決める**：機械判定しない。なぞ型をメインにした班は第7時に成果2件の有無を確認し、無ければ2番手へ。
- **匿名・班順は児童ごとにシャッフル・自班には貼れない・1人3枚**：人気や順番の偏りを抑える。
- **焦点（QFocus）が「？」で終わると先生画面で警告**：焦点は問いにしない（QFTの原則）。
- **画面**：付箋（--fill-b）とキラキラシール（#E0A43A、装飾）。タップ56px以上、IME変換中のEnterは無視、再描画で入力中の文字とカーソルを保持。
- **未確認のリスク**：GASへの約30人同時書き込み。研究授業前に実測し、軽いポーリング（10秒＋ゆらぎ）で負荷を抑える。3年生の入力速度。
