# 個人情報の ありか と 年度末の 扱い

理念 `principles/roster-year-transition.md` に 従う。列を 足したら この 一覧と 消し方を 一緒に 直す。

## どこに あるか（GAS版の スプレッドシート）
| シート | 列 | 中身 | だれに 見えるか |
|---|---|---|---|
| 名簿 | メール・組・班・番号 | 児童の アカウント と 所属 | 先生（画面）／児童には 自分の 分と 班の メンバーの 番号だけ |
| 先生 | メール | 先生の アカウント | 先生 |
| items | json の `author` | 付箋を 書いた 児童の メール | 先生だけ（児童には 送らない） |
| items | json の `doneBy` | 調査済みに した 時に **手で 書いた 名前**（自由記述） | 同じ 班の 児童・先生。先生の 一覧の コピーにも 入る |
| items | `by` | 最後に 書いた 人の メール | だれにも 送らない |
| stars | `viewer` | シール・いいねを 貼った 児童の メール | 先生だけ（児童には 記号か 班の 中の 番号順） |
| comments | `viewer` | コメントを 書いた 児童の メール | 先生だけ |
| comments／items | 本文 | 児童が 自由に 書いた 文（名前を 書く 可能性） | 範囲の 中の 児童・先生 |

- 児童の 端末（ブラウザ）には「自分の ？のたね」だけが 残る（個人情報は ふくまない）。
- 先生の「表を コピー」（Gemini 用）には 書いた 児童の メール・番号は 入らない。**ただし 本文・`doneBy`（手で 書いた 名前）・コメントは 入る**。外部 AI に 渡す 前に 見る。

## 年度末（単元が 終わったら）
この アプリは 単元ごとに 使う ので、年度を またいで 使い続けない 前提。
1. 必要な 記録（CSV・意見の 一覧）を 校内の 保存場所に 残す。
2. スプレッドシートの 名簿・先生 シートを 消す。items・stars・comments の メールは、統計に 使わないなら シートごと 消す。
3. **版の 履歴には 消す 前の 値が 残る**。完全に 消すには ファイルを コピーし（コピーには 版の 履歴が 引き継がれない）、デプロイを 付け替え、元の ファイルを 完全に 削除する（定石。この 環境では 確かめていない）。
4. 翌年度に 使う 時は 新しい スプレッドシートで `setup` から 始める（前の 年度の 名簿を 引き継がない）。
